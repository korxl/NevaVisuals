# NevaVis

Клиентский Fabric-мод для Minecraft Java **1.21.4** (Java 21). Установка — как у обычного мода.

## Что работает
- **GUI** (Right Shift): стеклянное окно, 12 разделов, поиск модулей, 10 тем + своя тема, настройки.
- **Music** — плеер: MP3 / OGG / WAV из `.minecraft/config/nevavis/music/`, Play/Pause/Next/Previous,
  Shuffle, Repeat, громкость, поиск, эквалайзер, автоподхват новых файлов, запоминание трека и громкости.
  Играет в отдельном потоке — работает при закрытом GUI. Имя файла `Исполнитель - Название.mp3` задаёт артиста и название.
- **Music HUD** — панель «сейчас играет» сверху экрана (появляется при смене трека).
- **HUD** — счётчик FPS и координаты (включаются в разделе HUD).
- **Custom Hurt Effect** — цветная вспышка по краям экрана при уроне (Visuals → включить модуль, есть настройки).
- Клавиши музыки (Play/Pause, Next, Previous) — назначить в Настройки → Управление → NevaVis.

## Получить JAR без компьютера (с iPhone)
1. Загрузите проект в репозиторий GitHub (см. ниже).
2. Откройте вкладку **Actions** → дождитесь зелёной галочки сборки (3–6 минут).
3. Откройте **Releases** (справа на главной странице репозитория) → скачайте `NevaVis-1.0.0.jar`.
   Либо Actions → нужный запуск → Artifacts → `NevaVis-jar` (это ZIP с JAR внутри).

## Установка мода (на ПК)
1. Установите Fabric Loader ≥ 0.16.10 для Minecraft 1.21.4 (fabricmc.net/use).
2. Положите в папку `mods`: **Fabric API 0.119.4+1.21.4** и `NevaVis-1.0.0.jar`.
3. Запустите игру, нажмите Right Shift в мире.
4. Положите музыку в `.minecraft/config/nevavis/music/` — она подхватится сама.

## Сборка в Codespaces (альтернатива)
`bash scripts/build.sh` → `build/libs/NevaVis-1.0.0.jar`.
